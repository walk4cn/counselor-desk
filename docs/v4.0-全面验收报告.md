# 辅导员工作台 v4.0 全面验收报告

验收日期：2026-08-12  
结论：Windows 桌面端和网页端的本次交付已完成可复现构建、真实浏览器回归和 Windows 安装包验证；发布包可作为 Windows 候选版本交付。

## 本次实机验收

### 网页端（真实浏览器）

以本机静态地址运行与发布版相同的 `index.html`，在真实浏览器中完成以下闭环；测试过程中仅使用虚构验收数据，并在结束前从产品界面删除。

- 学生台账的 `10 / 20 / 50 / 100` 分页选择可用；将条数改为 50 后刷新，分页状态仍为 50。
- CSV 从系统文件选择器进入“识别—预览—确认”流程；`社区/书院`、学生类型（含专科）、关注等级、关注类型、危机级别、解除预警等字段均被映射。确认导入后，按姓名检索到记录；刷新后记录仍在；再经二次确认删除后列表恢复。
- 批量选择、批量删除二次确认、取消删除、单条删除及搜索清空均完成页面级回归。
- 390px 窄屏下学生台账使用卡片布局，无页面横向溢出；“菜单”可打开/关闭侧栏遮罩，底部导航存在。
- 学生 XLSX 导出预览、恢复入口的系统文件选择器、党团模块的 XLSX/Word 导出入口均可实际打开；浏览器控制台错误为 0。

此前将浏览器验收标为无法启动的原因已确认：当时直接以 `file://` 打开本地文件，受浏览器安全策略拦截，并非工作台无法启动。改为受控的本机静态地址后，以上页面流程均已实际完成。

### Windows 桌面端（实际安装包）

- `desktop-electron-smoke.js`：源码 Electron 进程完成 SQLite 持久化、附件备份/恢复、恢复点和旧数据迁移报告验证。
- `desktop-packaged-smoke.js`：重新打包后的 `win-unpacked` 应用实际启动，强制断言 `sqlite: true`、`migration: true`，验证 ASAR 环境也加载结构化数据库。
- `desktop-installer-smoke.js`：NSIS 安装包静默安装到临时目录，确认生成卸载程序后完成静默卸载，退出码均为 0；静默路径默认保留用户数据。非静默卸载在实际安装包中会明确询问“仅卸载程序并保留数据”或“同时删除本机数据和附件”。

本次在旧安装产物中发现并修复了一个真实发布缺陷：原生 `better-sqlite3` 未被带入 ASAR 外的运行时目录，导致打包版退回 JSON 路径（`sqlite: false`）。现在构建配置将必要原生依赖复制到 `resources/native/node_modules`，桌面数据层在打包时从该目录加载。该问题已由打包应用本身的强制断言覆盖，后续构建若再次遗漏原生模块会直接失败。

- 单文件网页发布包：`output/辅导员工作台-v4.0.0/辅导员工作台.html`
- Windows x64 安装包：`../output/desktop/CounselorDesk-4.0.0-x64.exe`
- 可执行桌面构建验证：`npm run build:desktop && npm run test:desktop-electron`

- Windows 原生依赖打包配置：`desktop/electron-builder.yml`
- 卸载数据选择脚本：`desktop/installer.nsh`

## 已知平台边界

macOS 的 DMG/ZIP 打包、代码签名和公证必须在 macOS 主机执行；这是 Apple 工具链的宿主机要求，不影响本次已验证的 Windows 安装包和网页端交付。Chrome/Edge 的本次真实浏览器验收已经完成；其他浏览器和真实移动设备仍应在对外大范围发布前按使用手册的人工清单各做一次环境签收。
