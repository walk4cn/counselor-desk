# 用户手册

这份手册按辅导员常见的一天来组织：先掌握学生信息，再安排跟进，把材料和专题工作放回可回看的脉络，最后为备份与交接留好出口。

## 📱 手机端导航

手机端首次打开不会再用欢迎设置或每日问候遮住工作区。点击左上角菜单打开导航抽屉；点击抽屉外的遮罩、按返回键或按 Escape 可以关闭，关闭后焦点会回到菜单按钮。导航分组可以折叠，折叠后仍可用“搜索模块”找到入口；“全部展开”和“恢复导航”可恢复导航显示。业务档案和就业记录在手机端改为卡片阅读，摘要会自动换行，编辑、删除和 AI 操作仍保留在卡片底部。

手机访问电脑开发地址时不要使用 `http://127.0.0.1:4173/`，因为手机上的 `127.0.0.1` 指向手机自己。请使用电脑局域网地址、公开 Pages 地址，或打开 `output/辅导员工作台.html` 离线包。

## 👥 学生台账

学生台账是大多数工作的入口。可以导入 Excel / CSV，也可以逐条补充；班级、培养层次、住宿、关注类型等学校常用字段可按本校口径维护。导入时先确认字段映射和异常提示，未知列不应被当作无用信息直接删掉。

建议做法：先导入一个班级，检查学号、姓名、班级和专业；确认无误后再导入更大范围的数据。通过姓名、学号、班级和关注信息筛选，再进入档案查看相关记录。

### 分页、筛选与批量操作

- 在台账底部选择 10、20、50 或 100 条每页。当前页、每页条数、筛选、排序和视图模式会随工作区保存。
- 筛选既可以从姓名、学号、班级开始，也可以组合社区/书院、培养层次、学生状态、关注类型、危机等级和预警解除状态。
- 需要给当前筛选结果做共性调整时，先确认“当前页”还是“筛选结果”全选。批量编辑会先显示字段差异，批量删除会要求再次确认，并提供一次撤销入口。
- 表格、卡片、照片名册面向不同查看场景；大表可用顶部和底部横向滚动条，选择列与操作列会保持可见。
- 删除或筛选后不要急着回到第一页：工作台会保留一个仍然存在的合理页码；如找不到记录，先检查筛选方案和已保存视图。

## 💬 谈心谈话、重点关注与待办

谈话记录适合写清时间、对象、主题、要点、下一步和回访日期。重点关注、学业风险、请销假、住宿与任务等记录应避免把诊断性结论当作事实；需要专业评估、紧急处置或正式审批时，必须回到学校既有制度与专业渠道。

实用习惯：每写完一条记录，顺手补上“下一步谁来做、什么时候回看”。这样首页提醒、筛选和学生档案才会形成连续的工作线索。

### 首页领导统计视图

首页“领导统计视图”只显示数值汇总。可在“编辑”中命名视图并勾选需要的指标，保存后通过下拉框切换；“导出”只生成当前指标的 CSV。不要把该视图当作学生名单、心理档案或正式统计报表的替代品，涉及敏感名单与上报口径仍须遵循本校制度。

### 从记录到统一时间线

学生档案不是第二张学生表。它把谈话、危机跟进、成绩、住宿、奖惩、活动、工作留痕、党团与组织任职放到同一条时间线上，帮助回看“何时发生、已做什么、接下来谁处理”。时间线用于工作整理，不代替危机评估、医学判断或学校的正式处置流程。

## 🗂️ 资料库与专题台账

通知、模板、政策、讲话稿、资助、就业和其他工作资料可以分类归档。上传前注意文件是否包含敏感信息；共享材料时优先提供脱敏模板。班团组织、党团相关、成绩与专项台账应以本校制度为准，工作台用于辅助整理，不替代审批或认定。

### 专题入口怎么用

- **班团组织**：维护岗位、任期、空缺、换届、继任和批量任职；需要查个人经历时从学生档案时间线回看。
- **党员发展**：按申请、积极分子、发展对象、公示、异议、预备党员和转正的线索整理档案；正式程序、材料要求和审批权限以学校规定为准。
- **成绩与帮扶**：查看趋势、挂科分布、课程风险和班级对比；识别风险后建立或关联真实的学业帮扶记录。
- **奖惩、活动、住宿、工作留痕**：使用独立入口维护事实与附件，按学生或时间筛选后再纳入档案回看。

### AI 工作助手

AI 工作助手不是独立的聊天窗口：它会围绕当前学生、当前事项、当前页面和日期范围生成可审核的建议，再由你决定是否转成任务、谈话或工作留痕。它不会直接改写学生事实、心理、预警、纪律、资助或奖惩记录。

- 在 AI 工作台先添加模型连接，明确勾选允许的用途并设置每日成功调用上限。API 密钥只保存在桌面端安全存储或当前浏览器会话，不进入业务备份。
- 本地开发服务会自动通过同源中转请求模型，解决部分模型接口未开放浏览器跨域的问题；静态网页部署时，需要在模型连接中填写由你控制的 HTTPS 中转地址，并在中转服务启用令牌时填写“中转访问令牌”。令牌只保存在当前浏览器会话，不进入业务备份；中转服务只应允许可信网页来源和明确的模型域名，并应使用 HTTPS。
- AI 默认使用脱敏记录。生成前可以选择当前学生、班级、日期区间和当前页面；可以先预览将要发送的记录、字段和来源。身份、联系方式、心理、纪律、资助、预警、重点关注和附件等敏感分类必须明确授权，字段授权只对本次请求生效并留下审计记录。
- 生成结果会进入统一建议中心，而不是直接改写业务事实。生成前可以选择当前学生、班级和日期范围；从学生档案、谈话详情、任务或业务记录打开 AI 入口时，当前页面、当前事项 ID 和稳定 `student_id` 会自动带入。建议可按状态、关键词、用途、风险等级和来源筛选；可以选择当前结果并批量标记为已查看，但不会批量采纳或批量修改事实。建议依次经过草稿、待审核、已查看、已采纳，再由辅导员选择转为任务、谈话或工作留痕；转化后仍保留建议 ID、来源和 `student_id` 关联。
- 高风险、紧急或包含敏感分类的建议必须明确人工确认后才能采纳；来源缺失或标记“需要重新核验”的建议只能查看，不能转为任务、谈话或工作留痕。
- 学生、任务、谈话、成绩、帮扶、预警、心理、资助、就业意向/联系、业务档案、资料、班团和组织等列表的记录操作区会提供对应的“AI …”动作；它只把当前记录作为上下文生成建议或草稿，不会绕过建议中心直接改写原记录。手机端记录操作会随卡片布局显示，仍保留人工审核和转化流程。
- 如果模型请求失败或被取消，建议中心会显示失败状态和“重试上一次请求”。重试只复用请求范围、请求文本、来源和授权范围，不保存或重新展示 API 密钥；成功、失败和引用来源数量会计入当日统计。
- 生成请求会显示“正在请求”、取消和超时状态；直连模型或来源抓取超过等待时间会自动结束，并保留不含密钥的重试范围。模型未配置或 API 密钥缺失也会写入安全失败审计，不会消耗本次敏感字段授权。
- 敏感字段授权弹窗中点击“暂不授权”不会发送模型请求，也会立即清除本次待确认的“正在请求”状态；如果页面在刷新后保留了未完成状态，点击“取消请求”会清理它并恢复可重试状态。
- 本地政策、模板、素材、就业资源和业务记录默认优先作为来源。公开网页只能由你粘贴并明确触发抓取；页面会显示来源 URL、标题、抓取时间、最近核验时间和引用片段。外部来源显示“已核验”后才会进入新的 AI 上下文；抓取失败或核验失败会标记“需要重新核验”，旧记录仍保留但不会继续作为权威上下文，点击“重新核验”成功后才能再次引用。
- 通知改写、预警辅助和工作总结只生成候选内容；预警辅助的确认只记录“已人工查看”，不会改写预警、心理、纪律或资助结论。
- 工作总结可以填写起止日期。生成后先编辑草稿，再点击“确认写入工作留痕”；系统会保存日期范围和来源记录数量，便于回看。
- 证书识别需要选择支持图片输入的模型。图片识别结果先进入草稿，必须选择学生、检查字段并人工确认后才会写入获奖档案；系统不会把识别结果直接当作事实认定。当前不提供自动 PDF 视觉识别。

### 就业资源目录

- 就业资源页内置约 80 条常用官方入口，支持按关键词、地区、分类、适用对象、状态和收藏筛选。
- 资源可以收藏、编辑、标记“有效 / 待核验 / 失效”或删除。应用不会自动抓取和判断官网状态，核验日期和来源单位需要人工维护。
- 政策和就业资源网址只有通过地址安全校验后才会显示为可点击链接；如果地址格式异常、协议不受支持或包含登录凭据，页面会显示“网址待核验”，请编辑记录后再打开。
- 可信来源可用签名清单导入/导出；日常维护也可用 CSV，字段包括名称、网址、分类、地区、对象、来源、标签、核验日期、状态和收藏。导入外部 CSV 后建议先逐条核验网址。

## 📥 导入、导出与附件

- **导入前**：确认来源、查看表头、完成映射与预览；不认识的字段先保留或单独确认。
- **导入后**：抽查几条学生记录和关联数据，再处理原始文件。
- **导出前**：只选择确有必要的字段；对外发送前再次检查是否包含学号、电话、家庭情况、健康或其他敏感信息。
- **附件**：附件与业务记录同样需要备份；不要仅备份表格而遗漏谈话材料、照片或归档文件。

## 🛟 备份、换机与交接

重要操作前先备份。换电脑、清浏览器、重装系统或岗位交接时，不要只复制安装包或 HTML 文件；请使用工作台的备份/迁移入口并在目标设备完成恢复验证。详细步骤见 [备份与迁移](./v4-migration-and-backup.md)。

## 常见问题

**导入后找不到学生**：先清除筛选条件，再用学号或姓名搜索；确认导入预览中的字段确实映射到了学号/姓名。

**换电脑后数据不见了**：网页数据与桌面数据位置不同。请从原设备导出备份，再在新设备恢复，不要依赖浏览器同步。

**可以把备份发给同事吗**：只在学校制度允许、传输渠道受控、必要字段最小化的情况下进行；交接后应确认接收方已成功恢复。
