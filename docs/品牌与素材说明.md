# 品牌与素材说明

这份说明记录公开仓库主页的视觉约定、素材来源和替换边界，便于后续贡献者保持一致的高级感，而不是每次发布都重新猜一套样式。

## 视觉方向

### 主题

**Calm operations / 安静而可靠的日常运营**：画面强调“辅导员正在处理连续的学生工作”，而不是把产品包装成泛化的科技仪表盘。结构使用工程蓝图网格、稳定的水平线和少量状态色，保持秩序感。

### 令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 深空航蓝 | `#0b3a82` | 主按钮、品牌底色、导航选中态 |
| 信号青 | `#0bb4c4` | 链接、进度、焦点和次级强调 |
| 珍珠白 | `#f8fbff` | 卡片表面、反差和大面积留白 |
| 琥珀 | `#e0a020` | 需要注意的节点、时间线锚点 |
| 翠绿 | `#12a06b` | 成功、已保存、恢复完成 |

字体沿用应用内的系统无衬线栈，以中文可读性为第一优先；标题使用更紧的字距，数据与状态标签使用稳定的数字宽度。

## 生成式素材记录

`counselor-desk-hero.png` 与 `illustration-recovery.png` 由 OpenAI 图像生成模型根据本仓库的视觉 brief 生成，再复制到 `assets/` 作为项目素材。提示词要求不出现可读文本、品牌 Logo、真实人物或真实学生信息，方便公开仓库安全传播。

替换图片时应保持：

1. 深空航蓝 / 信号青主色关系不变；
2. 画面不包含真实学生姓名、头像、学号或学校内部标识；
3. README 中的替代文本与图片内容同步；
4. 图片压缩后仍应适合 GitHub 首屏（建议单张不超过 2.5MB）；
5. 新增第三方图片必须在此处记录来源、许可和裁切方式。

## 图标使用原则

- 业务图标优先使用 `index.html` 内的 SVG symbol，保证离线和窄屏一致。
- README 的 emoji 只用于快速建立信息分组，不替代按钮文字或无障碍标签。
- 新增图标必须有 `aria-label` 或可见文字，不使用颜色单独传达状态。
- 不把生成式位图当作 Logo；Logo 和 favicon 继续保持可缩放 SVG。
