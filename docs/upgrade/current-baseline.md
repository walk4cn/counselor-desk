## 当前技术与数据事实

- 工作台是本地优先系统，可作为网页、单文件离线 HTML 和 Electron 桌面端运行。
- 浏览器侧以 IndexedDB/schema v8 为主，并保留 localStorage 兼容与迁移路径。
- Electron 侧使用 SQLite 仓储、IPC 桥和加密附件目录。
- 学生及大部分业务记录通过学号和稳定 ID 关联，学生时间线已经能够汇总多个业务集合。
- 已有导入预览、字段映射、冲突处理、批量操作、导入回滚、备份、交换包、便携 HTML、附件和版本历史能力。
- 已有本地 AI 模型配置、跨模块上下文、字段级脱敏授权、调用审计、统一建议中心、工作留痕草稿、通知改写、来源检索和预警辅助分析入口；模型可配置用途授权、每日成功调用额度、图像能力和可选中转地址，输出均须人工确认。上下文按当前学生、班级、日期区间、当前页面、当前事项和选定来源组合，默认使用稳定 `student_id` 并移除姓名、学号、联系方式等敏感出站字段；明确授权的敏感分类只对当前请求恢复对应字段，内部 `student_id` 始终不出站。建议保存于 `v4_ai_suggestions`，同时保存模型快照、审计编号、来源和风险等级；来源保存于 `v4_ai_sources`，授权保存于 `v4_ai_consents`，可按状态、关键词、用途、风险等级和来源筛选，可查看、采纳、驳回并转任务、谈话或工作留痕；当前结果可批量标记已查看但不能批量采纳。失败或取消的请求可无密钥重试，工作台显示当日调用、成功、失败和引用来源统计。外部来源增加已核验、需要重新核验和核验失败状态；核验失败的来源保留历史记录但从新上下文排除，重新核验成功后恢复引用，目录和引用详情显示 URL、标题、抓取时间、最近核验时间和片段。学生档案、谈话详情、任务和业务记录编辑入口会记录当前页面、事项 ID 和稳定 `student_id`，学生摘要与谈话 briefing 可从详情直接生成。内置业务页面均有统一的当前页 AI 动作入口，详情页另提供专属动作；开发服务提供同源 AI 中转，避免浏览器 CORS 拦截；静态部署需要单独运行受控 HTTPS 中转端。证书识别以待确认草稿保存，确认后才以稳定学生 ID、附件引用写入奖励档案。
- 当前就业资源种子数据约为 80 个官方或可信入口，带来源、分类、地域、适用对象、核验状态与本地收藏筛选基础；就业意向和联系全过程已形成独立记录流程，并以稳定学生 ID 优先、学号兼容的方式关联画像。

## 当前主要入口和存储边界

现有导航包含 `home`、`students`、`talks`、`tasks`、`worklogs`、`stay`、`leave`、`honor`、`pleave`、`attend`、`node`、`orgs`、`party`、`rewards`、`activities`、`warn`、`help`、`grades`、`grant`、`focus`、`psych`、`graduate`、`policy`、`material`、`comp`、`tpl`、`learning` 和 `bridge` 等入口。

学生画像的扩展必须沿用现有学生号/稳定 ID 关联。新增记录至少需要明确：所属业务集合、学生引用、发生时间、状态/等级、正文或数值字段、附件引用、创建/更新时间、schema 版本和审计要求。具体字段以对应现有记录定义为准，不在本基线中凭空改名。

## 参考 UI 的统一结论

已检查的参考界面覆盖证书识别、工作总结、党团发展、就业意向与联系、资源收藏、工作台/学生画像、风险建议、通知改写、模型配置权限、处分详情、班会记录和竞赛资源等场景。

后续实现必须逐场景复核以下内容：

- 页面层级：工作台概览、列表/筛选、详情/画像、编辑/确认弹窗。
- 操作边界：新增、编辑、批量处理、导入、附件、导出、AI 生成、人工确认和撤销。
- 状态呈现：空数据、加载、识别中、草稿、已确认、失败、无权限和敏感字段脱敏。
- 视觉一致性：沿用现有浅色工作台配色、紧凑信息布局、表格/标签/按钮体系；参考图用于补齐信息结构，不替换现有成熟交互。

## 移动端与本地地址

移动端的 `127.0.0.1` 指向手机自身，不能访问电脑上的 `4173` 开发服务。手机应使用公开 Pages 地址、电脑局域网地址，或直接打开 `output/辅导员工作台.html`。`http://127.0.0.1:4173/` 只适合在运行服务的电脑本机验收。

### 外链与窄屏卡片收口

- 政策智库和就业资源的外链统一经过 `CWB.utils.safeExternalUrl()`：只接受绝对 `http`/`https` 地址，拒绝危险协议、相对地址、控制字符、过长地址和用户名/密码；原始字段仍保留用于人工修正和导出，未通过校验的记录只显示“网址待核验”，不会生成可点击链接。
- 就业资源卡片的操作区允许换行。动态插入的记录级 AI 动作在 `360×800` 和 `390×844` 下不会把卡片撑出视口，也不会造成页面横向滚动。
- 新增 `tests/external-url-safety.js`，覆盖 URL 协议/凭据/长度边界、政策和就业页面渲染，以及窄屏动作区换行约束；内置浏览器已复核现有政策和就业资源链接均为合法 `http/https`。

## 数据与 AI 安全边界

- AI 默认只接收脱敏后的业务上下文；姓名、学号、联系方式、心理、纪律、资助等敏感内容需要明确授权。
- AI 结果统一作为草稿、建议或待确认结果，不直接改变预警、处分、资助、心理结论或学生档案。
- 证书识别必须经过学生匹配和人工确认后才写入获奖档案。
- 周报、月报和学期总结只能基于已有记录生成，不补造事实。
- API 密钥不进入导出包或普通备份；调用、授权、失败和额度变化需要可审计。
- AI 中转只转发必要的模型请求，不接受客户端任意请求头；服务端要求显式来源、可选访问令牌和允许模型域名清单，拒绝 DNS 解析到内网或特殊地址、非 HTTPS 目标、重定向和超大响应，密钥不写入日志、审计或备份。
