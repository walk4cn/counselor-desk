# 辅导员工作台 v4.0 架构与验收说明

## 数据安全与恢复

网页端通过 IndexedDB 镜像业务数据，并保留 JSON/便携 HTML 备份入口；桌面端通过 Electron 将快照、事务日志、附件库和恢复点写入系统用户目录。桌面端优先使用 `better-sqlite3` 的 WAL 结构化数据库，同时保留原子 JSON 快照作为可恢复回退。快照版本为 `schemaVersion: 7`，写入使用临时文件改名；异常退出时由最近恢复点继续工作。自动备份保留最近 20 个恢复点，卸载程序默认保留用户数据。

附件复制到受管理附件库，保存关联业务 ID、原文件名、MIME、大小、哈希和创建时间。完整备份包含附件元数据和文件内容；删除记录时由界面明确选择是否同步删除附件，避免误删。

### 打包版 SQLite 运行时

原生 Node 模块不能从 `app.asar` 内直接加载。因此 Windows 构建会把 `better-sqlite3`、`bindings` 和 `file-uri-to-path` 复制到 `resources/native/node_modules`；`desktop/database.cjs` 在开发环境按普通依赖加载，在打包环境从该受管理目录加载。`desktop-packaged-smoke.js` 对实际打包应用强制断言 `sqlite: true` 与 `migration: true`，防止构建遗漏原生数据库运行时而静默退回 JSON 路径。

## v4 功能边界

- 学生台账：10/20/50/100 分页、状态记忆、批量删除、固定操作列、社区/书院和专科生字段。
- 导入：序号列与多序号决策、危机/关注字段别名、导入预览、撤销和班级自动补充。
- 业务模块：党团建设、奖惩管理、活动开展、工作留痕、住宿情况、成绩管理；谈心和业务记录均可关联附件。
- 规则：成绩挂科与调宿阈值按班级覆盖，自动生成帮扶或首页预警并展示触发依据；危机等级可关联谈话频率。
- 导出：默认 XLSX，支持字段预览和可编辑 DOCX；附件在 Word 中以清单引用，不嵌入文档。

## 桌面端发布与迁移

桌面工程位于 `desktop/`，使用 Electron + electron-builder。Windows 输出 NSIS 安装包，包含卸载程序；非静默卸载会明确询问“仅卸载程序并保留数据”或“同时删除本机数据和附件”，静默卸载默认保留数据。启动迁移会探测旧 JSON 与便携 HTML：已迁移、跳过和冲突都会写入报告，已有新数据时不会被旧数据覆盖。

Windows 构建已完成源码 Electron、实际打包应用、NSIS 安装及卸载验证，覆盖 SQLite 加载、附件备份/恢复、自动快照和旧数据迁移。大范围发布前仍应在目标学校设备完成升级覆盖、受限目录、磁盘不足和大附件容量演练。macOS 的 DMG/ZIP、签名与公证必须在 macOS 主机执行。

公开仓库的视觉与发布资料也纳入 v4.0 维护面：README 使用本地优先主视觉，`assets/` 中的 Logo、favicon、横幅和生成式插图有统一令牌与来源记录；跨平台当前签收状态见《[平台构建矩阵](./平台构建矩阵.md)》，主页与文档同步流程见《[公开仓库维护指南](./公开仓库维护指南.md)》。
