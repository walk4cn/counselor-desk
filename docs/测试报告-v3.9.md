# 辅导员工作台测试报告（v3.9 基线与 v4.0 增量）

测试日期：2026-08-12
当前结论：v3.9 基线能力保持通过；v4.0 已完成网页实机回归、Windows 桌面源码/打包/安装卸载验证。

## v3.9 基线

- 覆盖页面渲染、18 个模块导入导出与增删改闭环、学生安全导入、示例恢复、公开接口和 5,000 行压力场景。
- 覆盖 UTF-8、UTF-8 BOM、GB18030、错误表头、重复列、重复学号、前导零、公式文本、非法日期与超长内容。
- 基线边界仍然成立：项目是本地优先应用，不提供账号、云端存储、自动跨设备同步或跨设备冲突合并；真实敏感数据不得用于测试。

## v4.0 增量

- 自动化：`v4-core`、`v4-ui`、`v4-import`、`v4-modules`、`v4-orgs`、`v4-attachments`、`v4-grades`、`v4-docx`、`p0p1`、`desktop-contract`、`desktop-runtime` 等套件覆盖学生分页/批量操作、序号决策、班团岗位、附件、成绩帮扶、DOCX/XLSX、自动保存和恢复。
- 网页端真实浏览器：完成分页状态刷新恢复、CSV 选择器导入—预览—提交—刷新—删除、批量删除二次确认、390px 卡片/侧栏/底部导航、导出预览和恢复文件选择器；控制台错误为 0。
- 桌面端：源码 Electron 冒烟验证 SQLite、附件备份恢复和旧数据迁移；重新打包后验证实际 `win-unpacked` 进程输出 `sqlite: true`、`migration: true`；NSIS 安装包完成静默安装、发现卸载程序并静默卸载。
- 本次修复：Windows 打包原先遗漏 `better-sqlite3` 原生运行时，导致打包版 SQLite 退回路径。构建已改为将依赖放入 `resources/native/node_modules`，并用打包冒烟测试强制断言阻断回归。
