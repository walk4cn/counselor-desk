# 辅导员工作台 v4.0 P0/P1 实施与验收

本批次将 P0 稳定性底座与 P1 高频工作流落到单文件网页和 Electron 桌面端共享的数据模型中。网页端以 IndexedDB + 本地备份运行；桌面端以系统用户目录 SQLite、原子 JSON 快照、事务日志和受管理附件目录运行。

## P0：稳定性底座

- 顶部显示“已保存 / 保存中 / 保存失败 / 恢复中”；所有集合写入均记录事务并触发自动保存。
- 启动时检查最近恢复点；本地设置缺失而快照有效时可恢复，受损快照不会被覆盖。
- 当前视图、筛选和学生分页条数写入 UI 状态；真实浏览器中将分页改为 50 后刷新仍保留 50。
- 附件单文件限制 25MB；同记录按摘要去重；桌面端附件写入失败会回滚索引；完整备份与恢复包含附件。
- 桌面端源码、打包应用和 NSIS 安装包均验证 SQLite、迁移、备份/恢复与卸载程序；非静默卸载明确选择保留数据或删除数据/附件，静默卸载默认保留；打包冒烟测试强制要求 SQLite 成功加载。

## P1：高频业务流程

- 学生导入提供字段映射预设、自动匹配和复用；多序号列要求用户在预览中决策。
- 学生档案时间线汇总谈心、留痕、党团、奖惩、成绩、活动和住宿事件；班团职务可与班级学生双向关联。
- 谈心页依危机等级、最近谈话与频率规则生成待办；成绩页按学期统计挂科并联动学业困难帮扶。
- 素材库支持标题、分类、来源、标签、正文和备注的全文检索；学生与各 v4 模块支持统一批量选择与删除。
- XLSX/Word 导出可预览字段与版式，附件以清单引用。

## 本次真实网页回归

在真实浏览器中执行：学生分页持久化、CSV 系统文件选择器导入—预览—确认—刷新恢复—删除、批量删除二次确认、窄屏卡片/侧栏/底部导航、XLSX 导出预览、恢复文件选择器，以及党团模块的 XLSX/Word 导出入口。全程使用临时虚构数据，结束时从应用内删除；控制台错误为 0。

## 验收命令

```powershell
npm test
npm run lint
node tests/p0p1.js
npm run build:package
npm run build:desktop
npm run test:desktop-electron
```

`tests/p0p1.js` 覆盖保存状态、视图恢复、列表窗口标记、附件去重/超限/失效链接、映射预设、档案时间线、谈话排程、成绩趋势、素材检索和批量入口。Windows 桌面端的打包 SQLite、迁移和安装/卸载回归由 `desktop-electron-smoke.js`、`desktop-packaged-smoke.js` 和 `desktop-installer-smoke.js` 覆盖。
