# 文档中心

欢迎来到辅导员工作台 v4.4.0 的文档中心。这里按“第一次使用、完成一件事、查一项规则、参与改进”组织内容，让老师先找到能完成眼前工作的说明，再按需要进入数据、安装和开发资料。

> **v4.4.0 已正式发布。** 它聚焦学生分页与批量管理、专项模块入口、统一时间线、schema v8 迁移恢复、欢迎体验、性能与跨平台发布门禁。[在线体验](https://7752777.github.io/counselor-desk/) 与 [v4.4.0 Release](https://github.com/7752777/counselor-desk/releases/tag/v4.4.0) 已可使用；平台、哈希和签名状态请以 [版本与发布状态](./v4-acceptance-report.md) 为准。

## 文档使用约定

- 所有示例、截图、Issue 和讨论都只能使用虚构或脱敏数据。
- 下载文件、平台支持、哈希与签名状态以 Release 页面实际内容为准。
- 公开版文档只记录已经验证的事实；当前 v4.4.0 的发布提交、平台门禁和下载边界已记录在发布验收页。

## 怎么找到需要的内容

- 想先看产品实际界面：打开 [在线体验](https://7752777.github.io/counselor-desk/) 或回到仓库首页查看八张虚构数据截图；正式数据请优先在受控设备的离线或桌面端使用。
- 想快速完成一件工作：从“完成一件事”表格进入相应操作页，而不是先阅读开发文档。
- 想核对版本是否可下载：只看 [版本与发布状态](./v4-acceptance-report.md) 和 GitHub Release 的真实附件。
- 想参与代码或测试：先阅读 [开发与构建](./development.md)；面向使用者的页面不承载内部调试过程。
