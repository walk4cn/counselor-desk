# 文档中心

欢迎来到辅导员工作台 v4.4.0 的文档中心。这里按“第一次使用、完成一件事、查一项规则、参与改进”组织内容，避免把源码笔记、内部计划和用户说明混在一起。

> **v4.4.0 是本次完整升级版本。** 它聚焦学生分页与批量管理、专项模块入口、统一时间线、schema v8 迁移恢复、欢迎体验、性能与跨平台发布门禁。现有 Pages 仍是等待替换的旧站；请通过 [版本与发布状态](./v4-acceptance-report.md) 区分“已集成的 v4.4 能力”和“已公开的 Release 附件”。

- 所有示例、截图、Issue 和讨论都只能使用虚构或脱敏数据。
