# 架构概览

辅导员工作台采用本地优先的架构：同一套业务页面可以作为网页、离线 HTML 或桌面端运行，数据处理尽量留在用户可控的设备上。

## 三个使用层

| 层 | 作用 | 使用者关心什么 |
| --- | --- | --- |
| 网页与离线 HTML | 快速打开、演示、轻量使用 | 浏览器本地数据不会自动迁移到另一台电脑。 |
| 桌面端 | 固定电脑上的本地资料、附件与备份 | 安装包与用户数据目录不同；升级前应备份。 |
| 导入/导出/备份 | 在系统、设备和交接之间传递资料 | 只传递必要数据，恢复前保留当前快照。 |

## 设计原则

- **本地优先**：不强制项目账号，不把学生业务数据设计为项目服务器的默认资产。
- **显式确认**：导入、覆盖、删除、恢复等高风险动作应先预览、确认并留下退路。
- **可携带**：数据应能通过明确的导出与备份路径迁移，而不是被锁在某个浏览器或安装目录中。
- **兼容优先**：面对不同学校的表头和字段口径，先保留信息，再逐步规范。
- **验证优先**：网页、桌面端、附件、迁移和恢复需要各自测试；任一平台未验证，不应被包装成“全平台完成”。
