# 架构概览

辅导员工作台 v4.4.5 延续本地优先架构：同一套业务页面可以作为网页、离线 HTML 或桌面端运行，数据处理尽量留在使用者可管理的设备上。它的目的不是搭建中心化平台，而是让一线记录、附件、导入、AI 建议和恢复有清楚的边界。

## 三个使用层

| 层 | 作用 | 使用者关心什么 |
| --- | --- | --- |
| 网页与离线 HTML | 快速打开、演示、轻量使用 | 浏览器数据不会自动迁移到另一台电脑；便携模式不会读取或写入普通网页的数据空间。 |
| 桌面端 | 固定电脑上的本地资料、附件与备份 | 用户数据与安装目录分开；升级、卸载和换机前应先建立备份。 |
| 导入/导出/备份 | 在系统、设备和交接之间传递资料 | 只传递必要数据，恢复前保留当前快照，附件与业务记录一起抽查。 |

## v4.4.5 数据工作区

v4.4.5 使用 **schema v8** 作为工作区数据格式。迁移时保留稳定内部 ID、附件关联、历史学号和自定义字段，并在转换前创建恢复点。数据写入通过串行队列处理，提供保存状态、失败重试、版本历史、恢复点和诊断信息；浏览器主存不可用时会进入可见的兼容模式并提示应急导出。AI 建议、来源、授权和审计作为独立集合进入同一工作区边界，不自动改写学生事实。

为保持已有扩展和自动化脚本的兼容性，`window.CWB` 继续可用；同时公开以下稳定命名空间：

| 接口 | 用途 |
| --- | --- |
| `CWB.workspace` | 写入、检查点、刷新、状态、重试、版本历史和恢复。 |
| `CWB.views` | 个人列视图、筛选方案与显示配置。 |
| `CWB.leadershipViews` | 领导统计视图的数值指标、保存视图、选择、编辑、删除与导出支持。 |
| `CWB.imports` | 导入任务、进度、暂停、取消、重试与冲突处理。 |
| `CWB.exports` | 字段选择、脱敏、版式与导出审计。 |
| `CWB.diagnostics` | 存储状态、异常信息和应急诊断包。 |

附件二进制仍由专门的附件仓保存；工作区只保存附件元数据和关联关系，避免把大文件复制进每一条版本历史。

领导统计视图存放在工作区设置的 `leadership_views` 与 `leadership_view_id` 字段中。它与个人列视图分开，避免字段配置的异步写入覆盖统计视图；任何共享设置写入都必须保留这两个字段。旧版存于 `personal_views` 且标记为 `kind: 'leadership'` 的记录会在读取时规范化并补齐默认指标。

## 设计原则

- **本地优先**：不强制项目账号，不把学生业务数据设计为项目服务器的默认资产。
- **显式确认**：导入、覆盖、删除、恢复等高风险动作先预览、确认并留下退路。
- **可携带**：数据通过明确的导出与备份路径迁移，而不是被锁在某个浏览器或安装目录中。
- **兼容优先**：面对不同学校的表头和字段口径，先保留信息，再逐步规范。
- **验证优先**：网页、桌面端、附件、迁移和恢复需要各自测试；任一平台未验证，不包装成“全平台完成”。

## 测试分层

v4.4.5 的测试分为四层：纯运行时与迁移单元测试、浏览器/IndexedDB 回归、页面操作与性能回归、以及 Windows/macOS 包级烟测。发布门禁按“测试 → Windows → macOS → 网页产物 → Release → Pages”执行，并额外检查公开面和凭据扫描；跳过、缺件或未在目标平台完成的测试均不能当作通过。
