# 版本与发布状态

本页是公开事实记录，不是愿望清单。读者应以 [Releases](https://github.com/7752777/counselor-desk/releases) 中的实际版本、附件、哈希与说明为最终依据。

## v4.4.0 版本定位

- **本次产品版本**：v4.4.0。该版本统一了 v4.1 的可靠保存、v4.2 的学生台账、v4.3 的专项模块和 v4.4 的发布收口工作。
- **代码状态**：v4.4.0 候选分支为 `codex/v4.4-integration`。当前功能基线 `cb4558d280d922548c82e7fce672badfedec2297` 已在 D 盘隔离缓存与临时目录完成完整主测试回归；它将大批量导入的默认工作单元切细为 128 条，保留 200ms 浏览器响应门槛与全部落盘校验。PR #1 的最终提交仍须重新通过 HTML / JS 语法检查与完整测试门禁。最终发布 SHA、CI 产物哈希与公开发布链接只会在正式发布后补入。
- **在线体验**：现有 GitHub Pages 还是旧站，等待 v4.4.0 通过发布门禁后切换。它不能作为 v4.4 功能是否已上线的判断依据。
- **桌面包**：只以 `v4.4.0` Release 中实际存在的 Windows/macOS 附件、SHA-256、签名和公证说明为准。
